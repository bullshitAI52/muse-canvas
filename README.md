# 多图工作流画布（Muse Canvas Workflow）

一个节点式的无限画布生图工作流空间，参考 [openai-canvas-portable](https://github.com/bullshitAI52/openai-canvas-portable) 的工作流设计，但**不需要任何外部 API Key**：参考图分析、提示词整理和图片生成全部由 Muse 执行。

## 工作流

参考图 → LLM 提示词节点 → 生成节点 → OUTPUT 结果节点。连线决定哪些图片参与哪一步，连线顺序就是提示词里的图1、图2 编号。

- **IMAGE 节点**：上传参考图，可标注角色（人物、服装、场景、动作构图、商品、风格）
- **LLM 节点**：结合连入的参考图和你的要求，生成可直接生图的提示词（节点模式 / 聊天模式双模式），输出可手动修改
- **生成节点**：按提示词 + 连入的参考图生成图片；可一键运行（先分析再生成）或单步执行；画幅（横 / 竖 / 方）与数量（1–4 张）可调
- **OUTPUT 节点**：查看与下载生成结果

## 功能

- 深色无限画布：拖动节点、平移、缩放，点端口连线，打开项目自动适应画布
- 多项目切换，画布自动保存
- 生成历史：自动保存生成图、提示词与参数，可复用作参考图或同提示词再生成
- 工作流导入 / 导出 JSON
- 首次打开自带经典布局：6 个参考图位（人物 ×2、场景 ×2、服装 ×2）预连线

## 技术结构

- `client/`：前端（React + TypeScript），画布与节点交互
- `server/`：服务端 actions（项目、画布、LLM 分析、生图、历史）
- `drizzle/`：数据库迁移
- 本仓库是该空间的源码存档；在 Muse 中运行时，LLM 分析与生图由 Muse 平台管线执行
